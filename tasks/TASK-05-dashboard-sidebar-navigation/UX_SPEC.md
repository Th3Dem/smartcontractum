# UX_SPEC.md — Интерфейсная спецификация: Боковое меню и разделы (TASK-05)

## 1. Компоновка интерфейса (Dashboard Shell Layout)
- **Левый сайдбар (`.dash-sidebar`)**:
  - Ширина: 250px, фиксированная или липкая (`position: sticky; top: 0`).
  - Верхний блок: логотип **SMARTCONTRACTUM** с фирменным щитом.
  - Навигационный блок:
    - **«Основные»** (иконка пользователя/профиля) — класс `.nav-item.active`.
    - **«Безопасность»** (иконка щита/замка) — класс `.nav-item`.
  - Нижний блок: кнопка смены темы (🌙 / ☀️), кнопка «Выход».
- **Правая контентная область (`.dash-main-wrap`)**:
  - Заголовок раздела с динамическим заголовком и описанием.
  - Плавное переключение разделов через анимацию `fadeIn 0.2s ease`.

---

## 2. Раздел 1: «Основные» (`#section-general`)
- Карточка профиля с крупным аватаром, именем, бейджем типа субъекта и кнопкой «Редактировать данные».
- Таблица реквизитов:
  - Фамилия, Имя, Отчество
  - **Название блога** (выделено стильным акцентом)
  - Контактный телефон
  - Электронная почта
  - Дата регистрации
- В модальном окне редактирования добавлено поле `Название блога`.

---

## 3. Раздел 2: «Безопасность» (`#section-security`)
- **Карточка «Смена пароля»**:
  - Поле: `Текущий пароль` + кнопка 👁/🙈
  - Поле: `Новый пароль` + индикатор сложности (Password Strength Meter) + кнопка 👁/🙈
  - Поле: `Подтверждение пароля` + статус совпадения (✓ / ✕) + кнопка 👁/🙈
  - Кнопка: `Обновить пароль` (`btn-primary`).
- **Карточка «Стандарты безопасности и защиты данных (152-ФЗ)»**:
  - Информационная сетка: PBKDF2-HMAC-SHA256, токены сессий, SSL/TLS, аудит.
