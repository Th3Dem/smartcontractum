## 2. Инструкции по тестированию
1. Запуск автотестов:
   ```bash
   python3 -m unittest tests/test_sidebar_and_security.py
   python3 -m unittest discover tests
   ```
2. Ручная проверка:
   - Открыть `http://localhost:3000/dashboard.html`.
   - В левом меню кликнуть «Безопасность» $\rightarrow$ открывается форма смены пароля.
   - Ввести неверный текущий пароль $\rightarrow$ отображается ошибка.
   - Ввести верный текущий пароль и новый надежный пароль $\rightarrow$ отображается успешное уведомление.
   - Кликнуть «Основные» $\rightarrow$ нажать «Редактировать данные» $\rightarrow$ заполнить «Название блога» $\rightarrow$ сохранить и убедиться в обновлении.
