# SECURITY_REVIEW.md — Аудит безопасности смены пароля и навигации (TASK-05)

## 1. Защита эндпоинта `POST /api/user/change-password`
1. **Аутентификация**: Доступ разрешен только при наличии валидного Bearer-токена в заголовке `Authorization`.
2. **Проверка текущего пароля**: Обязательная сверка хэша текущего пароля с использованием `hmac.compare_digest()` (защита от атак по времени).
3. **Криптостойкость**: Новый пароль хэшируется по алгоритму **PBKDF2-HMAC-SHA256** со 100 000 итераций и свежей криптографической солью (`secrets.token_hex(16)`).
4. **Валидация длины**: Пароли длиной менее 8 символов блокируются на уровне сервера.

## 2. Вердикт
Механизм смены пароля и изоляция разделов соответствуют высшим стандартам безопасности и 152-ФЗ РФ.
