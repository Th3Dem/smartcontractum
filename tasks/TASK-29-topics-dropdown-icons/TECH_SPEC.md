# TECH_SPEC.md — Техническая спецификация векторных иконок меню (TASK-29)

## 1. Векторные SVG элементы
- Использование семантических viewBox `0 0 20 20` с `currentColor` для синхронизации цветов с `.glow-*` классами:
  - `glow-cyan`: Молния/вспышка (Все темы)
  - `glow-blue`: Код / скобки компилятора (EVM/Yul)
  - `glow-emerald`: Щит кибербезопасности (Аудит ИБ & ГОСТ)
  - `glow-sky`: Глобальная сеть / оракулы (Рынок внешних данных)
  - `glow-amber`: Банковские колонны (ЦБ РФ & Цифровой рубль)
  - `glow-violet`: Документ / эскроу (Смарт-эскроу & 1С)
  - `glow-gold`: Участники / биржа (Биржа заказов & команды)
