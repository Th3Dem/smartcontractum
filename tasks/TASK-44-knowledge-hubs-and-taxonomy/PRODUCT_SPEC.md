# PRODUCT_SPEC.md — Продуктовая спецификация хабов базы знаний (TASK-44)

## 1. Бизнес-цель
Обеспечить структурирование инженерного, аудиторского и правового контента платформы по 6 основным тематическим хабам. Позволить участникам сообщества и заказчикам быстро погружаться в конкретное технологическое направление, подписываться на обновления и отслеживать лучшие практики.

## 2. Пользовательские сценарии (User Stories)
- **US-01 (Навигация по хабу)**: Разработчик переходит в хаб «⚡ Разработка EVM & Смарт-контракты» и видит только материалы по Solidity, байткоду, EIP и оптимизации газа.
- **US-02 (Поиск правовых оснований)**: Корпоративный юрист открывает хаб «🏛️ Право, ЦБ РФ & ЦФА» и находит все актуальные шаблоны договоров по ст. 860.7 ГК РФ и нормативные акты Банка России.
- **US-03 (Подписка на хаб)**: Инженер подписывается на обновления хаба «🛡️ Аудит ИБ», чтобы получать новые статьи по уязвимостям в свою ленту.

## 3. Критерии приемки (Acceptance Criteria)
- **AC-01**: Маршрут `/hubs` отдает страницу витрины хабов знаний.
- **AC-02**: REST API `GET /api/hubs` возвращает все 6 хабов с актуальными счетчиками материалов и экспертов.
- **AC-03**: REST API `GET /api/hubs/<slug>` возвращает публикации и топ контрибьюторов выбранного направления.
- **AC-04**: В шапке сайта ссылка «База знаний» перенаправляет на `/hubs`.
- **AC-05**: Все автоматические тесты проходят успешно.
