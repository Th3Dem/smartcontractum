# TECH_SPEC.md — Техническая спецификация хабов базы знаний (TASK-44)

## 1. Архитектура и методы данных (`db.py`)
- Метод `get_hubs_list() -> list[dict]`:
  - Возвращает список 6 основных хабов с метаданными (название, иконка, описание, ключевые теги, счетчик статей, вопросов, экспертов, подписчиков).
- Метод `get_hub_details(slug: str) -> dict | None`:
  - Возвращает агрегированную информацию по конкретному хабу, включая список его недавних публикаций из `feed_posts` и топ экспертов из `user_reputation`.

## 2. REST API (`server.py`)
- `GET /hubs`, `/hubs.html`: отдача HTML страницы витрины хабов.
- `GET /api/hubs`: возвращает `{ success: true, hubs: [...] }`.
- `GET /api/hubs/<slug>`: возвращает `{ success: true, hub: {...}, posts: [...], experts: [...] }`.
