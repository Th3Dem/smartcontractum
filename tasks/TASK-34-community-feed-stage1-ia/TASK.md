## 2. Объем выполняемых работ (Scope)
1. **Навигация в шапке (`public/feed.html`)**:
   - Перевести верхнюю навигацию на целевую триаду: `Главная`, `Сообщество` (активно), `База знаний`.
2. **Кнопка действия CTA (`public/feed.html`, `public/forum_social.js`)**:
   - Заменить простую кнопку на `+ Создать` с выпадающим списком / модальным выбором: `Вопрос`, `Статья`, `Обсуждение`, `Кейс`, `Пост`.
3. **Фильтры ленты (`public/feed.html`, `public/forum_social.js`)**:
   - Перестроить вкладки ленты на: `Для вас`, `Подписки`, `Вопросы`, `Статьи`, `Обсуждения`, `Кейсы`.
   - Исключить смешение «Авторы» и «Компании» с типами контента.
4. **Поиск (`public/feed.html`, `public/forum_social.js`)**:
   - Установить целевой плейсхолдер: `Поиск по знаниям, людям и компаниям...`.
   - Поддержать живой поиск по авторам, компаниям, тегам и заголовкам.
5. **Карточки ленты (`public/feed.html`, `public/forum_social.css`)**:
   - Расширить сниппет автора: имя, роль, подтвержденная компетенция, накопленная репутация (`+1 420`, `+860` и т.д.).
   - Привести социальные действия к профессиональному стандарту: `Полезно ▲ (+N) / ▼`, `Ответы / Комментарии`, `Сохранить`, `Поделиться`, `Подписаться`.
   - Добавить явную маркировку демо-контента (`[DEMO]` / `Общественные консультации`), исключив ложное впечатление официальных заявлений Банка России.
6. **Правый сайдбар (`public/feed.html`)**:
   - Заменить статичный баннер на 3 динамических блока:
     1. `Сейчас обсуждают` (актуальные дискуссии и голосования стандартов);
     2. `Ждут ответа` (вопросы, требующие экспертного решения);
     3. `Эксперты сообщества` (лидерборд по компетенциям с кнопкой подписки).
7. **Тестирование**:
   - 30 / 30 PASSED (100% OK), проверка темной/светлой темы и мобильной верстки.
