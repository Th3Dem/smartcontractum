# UX_SPEC.md — Интерфейсная спецификация редактора статей (TASK-36)

## 1. Компоновка интерфейса `/editor`
- **Верхняя панель**: кнопка возврата «В ленту», заголовок, переключатели режимов (Редактор / Предпросмотр / Сплит), индикатор автосохранения («Черновик сохранен»), кнопка переключения темы (🌙/☀️) и основная кнопка «Опубликовать в базу знаний →».
- **Поля метаданных**:
  - Тип публикации (📄 Статья, ❓ Вопрос, 💬 Обсуждение RFC, 💼 Кейс);
  - Тематический раздел (6 направлений);
  - Теги через запятую;
  - Заголовок материала.
- **Панель форматирования**: жирный, курсив, заголовки H2/H3, цитата, списки, ссылка, **вставка смарт-контракта**, **вставка опроса RFC**, превью.
- **Превью смарт-контракта**: стилизованный блок темной темы с синтаксисом Solidity и бейджем расхода газа (`Gas: ~42 500`).
- **Двухрежимная тема**: адаптация под темную и светлую темы оформления.
