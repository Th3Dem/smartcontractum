# RELEASE_REPORT.md — Отчет о релизе редактора (TASK-36)

## 1. Сводка релиза
- **Версия релиза**: `v2.25.0`
- **Задача**: `TASK-36` (Продвинутый редактор статей, кода смарт-контрактов и RFC-консультаций)
- **Коммит**: `feat(TASK-36): advanced markdown editor, solidity blocks, rfc polls and direct api publishing`
- **Статус**: `RELEASED`

## 2. Ключевые изменения
1. Полнофункциональный интерфейс `/editor` с поддержкой 3 режимов отображения.
2. Поддержка 4 форматов (статьи, вопросы Q&A, обсуждения RFC, кейсы) и 6 разделов базы знаний.
3. Вставка сниппетов Solidity 0.8.26 и блоков голосований.
4. Автосохранение черновиков и типографирование текста в один клик.
5. Публикация в базу знаний через `POST /api/feed/posts`.
6. 44 теста в регрессионном наборе (100% OK).
