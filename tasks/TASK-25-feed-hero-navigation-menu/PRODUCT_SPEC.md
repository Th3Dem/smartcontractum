# PRODUCT_SPEC.md — Продуктовая спецификация навигационного меню в Hero-блоке (TASK-25)

## 1. Цель
Разместить на едином интерактивном фоне Hero-блока прямо под заголовком «Сообщество SmartContractum» панель быстрой фильтрации и навигации по ленте:
- Кнопки разделов: **«Статьи»**, **«Посты»**, **«Новости»**, **«Авторы»**, **«Компании»**.
- Яркая кнопка призыва к действию **«Написать»**, открывающая создание новой публикации.

## 2. Критерии приемки
- **AC-01**: В секции `.feed-hero-strip` под заголовком выводится панель навигации `.feed-hero-nav-bar`.
- **AC-02**: Присутствуют кнопки: «Статьи», «Посты», «Новости», «Авторы», «Компании» и кнопка «Написать».
- **AC-03**: Клик по кнопкам фильтрует поток публикаций или переключает фокус.
- **AC-04**: Клик по «Написать» вызывает модальное окно быстрого создания публикации.
- **AC-05**: 30 из 30 тестов проходят успешно.
