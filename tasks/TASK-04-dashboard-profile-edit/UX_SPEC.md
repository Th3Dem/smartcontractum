# UX_SPEC.md — Интерфейсная спецификация: Управление профилем (TASK-04)

## 1. Изменения в макете карточки профиля ([public/dashboard.html](file:///home/dem/Projects_01/public/dashboard.html))
1. **Удаление блока статуса**:
   - Строка `Статус учетной записи: ✓ E-mail подтвержден (Активен)` удаляется из разметки и шаблонизатора `renderUserProfile()`.
2. **Шапка карточки реквизитов**:
   - В `profile-header-box` справа добавляется кнопка с иконкой карандаша:
     - Кнопка: `<button id="btn-open-edit-profile" class="btn-edit-profile"><svg>...</svg><span>Редактировать данные</span></button>`
   - Дополнительно в каждой строке реквизитов (или по клику на карточку) предусмотрен быстрый доступ.

---

## 2. Модальное окно редактирования профиля
- **Оверлей**: затемнение фона с эффектом `backdrop-filter: blur(4px)`.
- **Заголовок**: «Редактирование данных профиля» с кнопкой закрытия (✕).
- **Поля ввода**:
  - `Фамилия` (для физлиц / ИП / представителей)
  - `Имя`
  - `Отчество`
  - `Контактный телефон` с маской `+7 (XXX) XXX-XX-XX`
  - `Электронная почта (E-mail)`
- **Кнопки управления**:
  - «Сохранить изменения» (`btn-primary` с индикатором отправки)
  - «Отмена» (`btn-secondary`, закрывает модальное окно)
- **Уведомления**:
  - Всплывающий баннер с успехом/ошибкой `dash-alert`.

---

## 3. Адаптивность и поддержка тем
- Модальное окно и элементы управления полностью адаптированы для Dark (`data-theme="dark"`) и Light (`data-theme="light"`) тем с плавными переходами `0.25s ease`.
- На мобильных устройствах (<768px) модальное окно разворачивается на всю ширину с удобными отступами для сенсорного ввода.
