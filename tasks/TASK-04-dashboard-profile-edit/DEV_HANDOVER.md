## 2. Инструкция по тестированию
1. Запустить автоматические тесты:
   ```bash
   python3 -m unittest tests/test_profile_update.py
   python3 -m unittest discover tests
   ```
2. Ручная проверка:
   - Войти в Личный кабинет (`http://localhost:3000/dashboard.html`).
   - Убедиться в отсутствии надписи «Статус учетной записи: ✓ E-mail подтвержден (Активен)».
   - Нажать «Редактировать данные».
   - Изменить Фамилию, Имя, Отчество, Телефон или E-mail.
   - Нажать «Сохранить изменения» и проверить мгновенное обновление таблицы реквизитов и аватарки.
