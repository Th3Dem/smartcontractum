# PRODUCT_SPEC.md — Продуктовая спецификация каталога и профилей экспертов (TASK-42)

## 1. Бизнес-цель
Закрыть ключевые потребности первого этапа платформы:
1. **Сформировать профессиональную репутацию**: предоставить специалистам публичный профиль с историей решений, статьями и подтвержденными компетенциями.
2. **Найти нужного участника рынка**: предоставить бизнес-заказчикам и интеграторам удобный каталог сертифицированных инженеров, аудиторов ИБ, юристов и интеграторов 1С.

## 2. Пользовательские сценарии (User Stories)
- **US-01 (Поиск эксперта по компетенциям)**: Бизнес-заказчик заходит в раздел «Эксперты», выбирает фильтр «🛡️ Аудит ИБ» или вводит поиск «Solidity» и видит список проверенных аудиторов со статусом верификации и рейтингом репутации.
- **US-02 (Просмотр портфолио специалиста)**: Заказчик кликает на эксперта и открывает карточку профиля с подробной информацией: статус верификации (ФЛ / ИП / ЮЛ по ЕГРЮЛ), количество принятых решений в Q&A, список написанных статей и кнопка «Связаться / Предложить проект».
- **US-03 (Подписка на обновления)**: Участник сообщества подписывается на эксперта, чтобы его материалы отображались во вкладке «Подписки».

## 3. Критерии приемки (Acceptance Criteria)
- **AC-01**: Маршрут `/experts` отдает страницу каталога специалистов.
- **AC-02**: REST API `GET /api/experts` возвращает список экспертов с поддержкой фильтрации по компетенциям и поисковой строки.
- **AC-03**: REST API `GET /api/experts/<id>` возвращает развернутый профиль с опубликованными материалами и решениями.
- **AC-04**: Поддержка темной и светлой тем оформления со 100% контрастностью.
- **AC-05**: Все автоматические тесты проходят успешно.
