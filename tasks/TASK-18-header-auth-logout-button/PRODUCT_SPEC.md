# PRODUCT_SPEC.md — Продуктовая спецификация кнопки выхода в шапке (TASK-18)

## 1. Цель
Упростить и сделать лаконичным интерфейс в правом верхнем углу:
- При авторизованной сессии не отображать длинное ФИО/имя пользователя, а выводить однозначную и быструю кнопку **«Выйти»**.
- При клике на кнопку «Выйти» моментально завершать сессию и сбрасывать токен, переводя интерфейс в гостевой режим «Войти / Регистрация».

---

## 2. Критерии приемки
- **AC-01**: При наличии `auth_token` в `localStorage` надпись на кнопке в правом верхнем углу равна **«Выйти»**.
- **AC-02**: При отсутствии `auth_token` надпись на кнопке равна **«Войти / Регистрация»** со ссылкой на `/auth.html`.
- **AC-03**: Клик по кнопке «Выйти» очищает данные авторизации (`auth_token`, `user_profile`, `user`) и обновляет страницу.
