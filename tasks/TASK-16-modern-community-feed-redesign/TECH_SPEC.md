# TECH_SPEC.md — Техническая спецификация современной ленты комьюнити (TASK-16)

## 1. Архитектура фронтенда
- `public/feed.html` — Одностраничный интерфейс ленты с реактивной разметкой, встроенными интерактивными компонентами (Polls, Q&A, Threads, Quick Creator Modal).
- `public/forum_social.css` — Современный dark/glassmorphic дизайн, анимации градиентов, индикаторы прогресса опросов, стилизация карточек авторов и мобильная сетка.
- `public/forum_social.js` — Реактивный контроллер ленты:
  - Local state management для постов, опросов, комментариев, закладок и кармы.
  - Поддержка мгновенного сохранения новых публикаций в `localStorage` и рендеринга в начало ленты.
  - Обработка кликов по вариантам опросов с расчетом процентов.
  - Обработка добавления комментариев в ветку.
  - Полнотекстовый поиск и фильтрация по тегам и форматам.
