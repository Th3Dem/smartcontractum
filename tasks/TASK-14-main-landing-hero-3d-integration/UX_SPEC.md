# UX_SPEC.md — Интерфейсная спецификация (TASK-14)

## 1. Компоненты UI
1. **Sticky Header**: Логотип со смарт-контрактом, пункты меню («Сценарии», «Дорожная карта», «Регистрация»), кнопка входа в ЛК.
2. **Hero 3D**:
   - 3-строчный градиентный заголовок: *«Здесь рождаются»* (белый) / *«российские»* (электрик) / *«смарт-контракты»* (изумруд).
   - 3D куб с квантовым ядром и орбитальными кольцами.
   - Canvas космических частиц.
3. **Дорожная карта ПКСК**: 4 карточки этапов (Публикация концепции, сбор ОС, НИР, Пилот).
4. **Constellation Graph**: Радиальные карточки сценариев и модальное окно выбора специалистов.
