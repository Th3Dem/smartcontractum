# UX_SPEC.md — Интерфейсная спецификация лендинга и навигации (TASK-13)

## 1. Главная страница (`index.html`)
- **Шапка (Header)**:
  - Логотип `SmartContractum` (клик возвращает в начало главной страницы).
  - Навигация по разделам: «База знаний», «Создать контракт», «Маркетплейс», «Разработчикам», «Проверка и аудит», «Сообщество».
  - Кнопка авторизации в правом верхнем углу:
    - Для гостей: кнопка **«Войти / Регистрация»** $\rightarrow$ переход на `/auth.html`.
    - Для авторизованных пользователей: кнопка **«Личный кабинет →»** с именем пользователя $\rightarrow$ переход в `dashboard.html`.
- **Интерактивный блок выбора маршрута (Intent Modal)**:
  - Модальное окно с выбором цели (Бизнес, Разработчик, Аудит, Обучение, Поиск партнера).
- **Секции продуктов, аналитики и сообщества**:
  - Полный интерактивный контент лендинга из прототипа.

## 2. Страница авторизации (`auth.html`)
- Сохраняет полный спектр возможностей: выбор типа учетной записи (Физлицо, ИП, Юрлицо), автоматическая загрузка реквизитов ФНС, капча, 2FA подтверждение email, сброс пароля.
- В шапке присутствует ссылка «← На главную» для удобного возврата на лендинг.
