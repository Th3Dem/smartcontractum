# PRODUCT_SPEC.md — Продуктовая спецификация исправления z-index меню «Темы» (TASK-28)

## 1. Проблема
Выпадающий список направлений «Темы» при открытии обрезался нижней границей Hero-блока (`overflow: hidden`) и перекрывался карточками следующего блока (`.quick-creator-card`), отображаясь позади них.

## 2. Критерии приемки
- **AC-01**: При открытии меню «Темы» выпадающий список полноценно и четко отображается ПОВЕРХ всех нижележащих блоков (`.feed-main-container`, `.quick-creator-card`, стрима постов).
- **AC-02**: Выпадающий список не обрезается границей секции Hero.
- **AC-03**: 30 из 30 тестов проходят успешно.
