## 3. Результаты ручного функционального тестирования
1. **Шаг 1 (Запрос сброса)**:
   - Клик «Забыли пароль?» на форме входа мгновенно открывает форму запроса E-mail.
   - Canvas-капча генерирует случайный защитный код.
   - При невалидном E-mail или неверной капче подсвечиваются ошибки.
   - При успешном заполнении отправляется реальное письмо через `smtp.yandex.ru:465`.
2. **Шаг 2 (Ввод кода)**:
   - Открывается окно ввода 6-значного кода с фокусом на поле ввода.
   - Обратный таймер 60 сек корректно отсчитывает время и открывает кнопку повторной отправки.
   - Ввод неверного кода выдает предупреждение с красной подсветкой.
3. **Шаг 3 (Установка нового пароля)**:
   - Открывается форма ввода нового пароля.
   - Password Strength Meter динамически оценивает сложность (Слабый $\rightarrow$ Средний $\rightarrow$ Надежный).
   - Проверка совпадения подтверждения пароля работает на лету.
   - Кнопки 👁 / 🙈 переключают видимость символов.
4. **Завершение**:
   - После клика «Сохранить новый пароль» система переключается на экран входа с предзаполненным E-mail и зеленым уведомлением об успехе.
   - Авторизация с новым паролем направляет в Личный кабинет (`dashboard.html`).
