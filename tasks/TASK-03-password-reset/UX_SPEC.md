# UX_SPEC.md — Интерфейсная и пользовательская спецификация сброса пароля (TASK-03)

## 1. Концепция и принципы взаимодействия
Процесс восстановления доступа должен быть максимально прозрачным, пошаговым, исключать ощущение потери контекста и предоставлять понятные подсказки на каждом шаге.

---

## 2. Экранная карта состояний (3 шага)

### Шаг 1: Запрос кода на E-mail (`#form-forgot`)
- **Заголовок**: «Восстановление доступа»
- **Подзаголовок**: «Введите E-mail, указанный при регистрации»
- **Поля**:
  - `forgot-email`: поле ввода E-mail с валидацией формата.
  - `forgot-captcha-input`: графическая Canvas-капча с кнопкой обновления.
- **Основная кнопка**: `btn-submit-forgot` («Отправить код для сброса пароля»).
- **Вторичная ссылка**: «← Вернуться к форме входа».

### Шаг 2: Ввод проверочного кода из письма (`#form-forgot-verify`)
- **Заголовок**: «Проверочный код»
- **Подзаголовок**: «Письмо с 6-значным кодом отправлено на: [email]»
- **Поля**:
  - `forgot-code-input`: центрированное поле с крупным моноширинным шрифтом (maxlength=6, placeholder `000000`), автофокус при открытии.
- **Таймер**: `forgot-timer-text` («Запросить код повторно через 60 сек.») $\rightarrow$ кнопка «Отправить код повторно» (`#btn-forgot-resend`).
- **Основная кнопка**: `btn-submit-forgot-verify` («Подтвердить код»).
- **Вторичная ссылка**: «← Изменить адрес E-mail».

### Шаг 3: Установка нового пароля (`#form-forgot-new-pwd`)
- **Заголовок**: «Новый пароль»
- **Подзаголовок**: «Придумайте надежный пароль для вашей учетной записи»
- **Поля**:
  - `forgot-new-pwd`: поле нового пароля + кнопка «Показать/Скрыть пароль» (👁 / 🙈) + Password Strength Meter.
  - `forgot-new-pwd-confirm`: поле подтверждения пароля + индикатор совпадения (✓ Пароли совпадают / ✕ Пароли не совпадают).
- **Основная кнопка**: `btn-submit-save-new-pwd` («Сохранить новый пароль»).
- **Вторичная ссылка**: «← Отмена и возврат к форме входа».

---

## 3. Микроанимации и состояния
- **Loading State**: при отправке запросов кнопки переводятся в `disabled`, иконка заменяется на `.spinner` («Отправка проверочного письма...», «Проверка кода...», «Сохранение пароля...»).
- **Ошибки ввода**: поле получает класс `.is-invalid` (красная рамка и мягкое свечение), сверху появляется алерт с пояснением.
- **Успех**: после шага 3 показывается зеленый алерт `🎉 Пароль успешно изменен! Введите новый пароль для входа в кабинет`, форма входа активируется, поле Email предзаполняется.
