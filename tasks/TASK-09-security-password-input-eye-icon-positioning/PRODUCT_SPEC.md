# PRODUCT_SPEC.md — Продуктовая спецификация позиционирования иконки «глаз» (TASK-09)

## 1. Проблема и цель
На экране управления паролем («Безопасность») кнопки показа пароля находились вне контекста самого поля ввода из-за отсутствия относительного контейнера `.input-wrapper`. Необходимо встроить иконку `👁` непосредственно в правую часть строки ввода («инлайн»), аналогично экранам авторизации и регистрации.

---

## 2. Пользовательские требования (User Stories)
- **US-01**: Как пользователь, при вводе нового пароля и подтверждения я хочу видеть иконку «глаз» прямо внутри поля ввода справа, чтобы интерфейс выглядел аккуратно и компактно.
- **US-02**: Как пользователь, при клике на иконку я хочу переключать маскирование пароля (`password` $\leftrightarrow$ `text`) со сменой значка (`👁` $\leftrightarrow$ `🙈`).

---

## 3. Критерии приемки (Acceptance Criteria)
- **AC-01**: Иконка `👁` позиционирована абсолютно (`right: 10px`) внутри границ инпута.
- **AC-02**: Текст вводимого пароля имеет отступ справа `padding-right: 40px` и не перекрывает иконку.
- **AC-03**: Клик по иконке переключает тип инпута между `password` и `text` и меняет иконку.
