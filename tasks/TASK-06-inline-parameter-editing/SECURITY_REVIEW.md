# SECURITY_REVIEW.md — Аудит безопасности построчного редактирования (TASK-06)

## 1. Контроль доступа и целостность
- Каждый запрос инлайн-сохранения параметра снабжен токеном `Authorization: Bearer <token>`, валидируемым по таблице сессий.
- Пользователь может модифицировать только собственную запись (защита от IDOR).
- Валидация типов, длин и форматов данных (E-mail regex, минимальная длина телефона).
- Выходные данные обязательно проходят санитаризацию через `sanitize_user_dict()`.
