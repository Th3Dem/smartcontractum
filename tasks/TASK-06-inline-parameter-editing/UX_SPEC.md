# UX_SPEC.md — Интерфейсная спецификация: Построчные кнопки изменения (TASK-06)

## 1. Компоновка строки реквизитов
- В режиме чтения:
  - Текст метки слева: `.detail-label` (приглушенный цвет).
  - Правая часть: `.detail-val-wrap` с флекс-контейнером:
    - Текущее значение `.detail-val`.
    - Компактная кнопка `.btn-row-edit` с иконкой карандаша и текстом «Изменить».
    - Кнопка аккуратно подсвечивается при наведении.
- В режиме редактирования:
  - Строка подсвечивается легким синим свечением / рамкой.
  - Поле ввода `.form-input-inline` занимает доступную ширину.
  - Справа две компактные кнопки:
    - `.btn-inline-save` (зеленая/синяя кнопка «✓ Сохранить» или иконка галочки).
    - `.btn-inline-cancel` (кнопка «✕» для отмены).
- Анимации:
  - Плавное появление поля ввода через `transition`.
  - Фокус на поле ввода сразу после нажатия кнопки «Изменить».
  - Обработка `Enter` (сохранить) и `Escape` (отменить).
