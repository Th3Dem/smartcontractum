# UX_SPEC.md — Интерфейсная спецификация (TASK-17)

## 1. Компоненты UI
1. **Hero-полоса**: Четкая маркировка независимой экосистемы, фазы НИР и метрики 5 продуктовых этапов.
2. **Панель создания**:
   - «Поделитесь инсайтом, задайте вопрос по смарт-контрактам или создайте опрос...»
   - Быстрые кнопки: 📄 Статья / Паспорт, 💬 Пост, ❓ Вопрос, 📊 Опрос RFC, 💼 Кейс внедрения.
3. **Фильтры**:
   - Потоки по направлениям (EVM, ИБ, Оракулы, ЦБ РФ, Смарт-эскроу, Биржа заказов).
   - Табы форматов: [🔥 Все] [📄 Статьи] [💬 Посты] [❓ Вопросы] [📊 Опросы RFC] [💼 Кейсы] [💰 Баунти].
4. **Карточки контента**:
   - Карточка кейса / паспорта: схема бизнес-логики, источник данных, статус верификации.
   - Карточка оракула: SLA, задержка обновления, стоимость запроса.
   - Карточка голосования RFC: шкалы прогресса, дедлайн голосования.
5. **Сайдбар**:
   - Карточка дорожной карты НИР ЦБ РФ.
   - Реестр доверенных источников данных (ЕГРЮЛ, Росреестр, ГИС ЕИС Закупки, ЦБ РФ).
   - Открытые гранты & заказы с биржи.
   - Лидерборд экспертов по отдельным компетенциям.
