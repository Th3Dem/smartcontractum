## 2. Стандарты безопасности
- **Хеширование паролей**: `PBKDF2-HMAC-SHA256` (100 000 итераций, 16 байт соль).
- **Защита от тайминг-атак**: `hmac.compare_digest`.
- **Сессионная защита**: 256-битный токен в заголовке `Authorization: Bearer <token>`.
- **Изоляция маршрутов**: автоматический редирект неавторизованных запросов.
