# UX_SPEC.md — Спецификация пользовательского интерфейса (TASK-02)

## 1. Концепция интерфейса
Минималистичное, профессиональное рабочее пространство с акцентом на чистоту данных и идеальную читаемость.

## 2. Структура интерфейса Личного кабинета
- **Шапка (Header)**:
  - Слева: Фирменный логотип `SMARTCONTRACTUM` со щитом.
  - Справа: Кнопка «Профиль» (активна), Переключатель темы оформления (🌙/☀️), Кнопка «Выход».
- **Основная карточка (Profile Card)**:
  - Аватар с инициалом пользователя.
  - Заголовок с полным именем / наименованием компании и бейджем категории субъекта.
  - Сетка атрибутов с фиксированной шириной подписей (`flex: 260px`) и моноширинным шрифтом для реквизитов (ИНН, ОГРН, КПП, телефон).

## 3. Темы оформления
- **Темная тема (`[data-theme="dark"]`)**: глубокий фон `#081322`, карточки `#0e223d`, текст `#f8fafc`.
- **Светлая тема (`[data-theme="light"]`)**: фон `#f5f8fc`, белые карточки `#ffffff`, границы `#dce5ef`, текст `#172333`.
