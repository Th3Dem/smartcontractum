# DATA_REVIEW.md — Аудит базы данных и схемы хранения (TASK-02)

## 1. Схема данных
- **СУБД**: SQLite 3 (`data/smartcontractum.db`)
- **Таблицы**: `users`, `sessions`, `contracts`
- **Индексы**: `users(email)`, `sessions(token)`, `contracts(user_id)`

## 2. Соответствие 152-ФЗ
- Локальное хранение на защищенных серверах в РФ.
- Разделение атрибутов по типам субъектов (Физлицо, ИП, Юрлицо).
- Защита от утечки учетных данных через санитизацию `sanitize_user_dict()`.
