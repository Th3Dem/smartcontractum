# SECURITY_REVIEW.md — Аудит безопасности двухфакторной смены пароля (TASK-07)

## 1. Защищенные механизмы
1. **Защита от тайминг-атак**: Сравнение проверочного кода и токенов смены пароля выполняется исключительно через функцию постоянного времени `hmac.compare_digest()`.
2. **Ограничение времени жизни токенов**:
   - Проверочный код E-mail: 10 минут (`expires = time.time() + 600`).
   - Одноразовый токен смены `changeToken`: 15 минут (`expires = time.time() + 900`).
3. **Защита от перебора (Brute-force)**: 60-секундный cooldown на повторную отправку писем на почту.
4. **Контроль сессии (Session Fixation & IDOR Protection)**:
   - Все запросы требуют валидного `Bearer` токена.
   - Смена пароля привязана к `user_id` из токена.
   - После изменения пароля сессия может быть сохранена либо обновлена.
