# DATA_REVIEW.md — Аудит модели данных (TASK-07)

## 1. Схема данных
- Все операции с паролем завершаются вызовом `db.update_user_password(email, new_password)`:
  - Генерация криптографически стойкой 16-байтной соли (`os.urandom(16)`).
  - Хеширование алгоритмом PBKDF2-HMAC-SHA256 (100 000 итераций).
  - Атомарное сохранение `password_hash` и `password_salt` в SQLite.
  - Инвалидация всех активных сессий пользователя в таблице `sessions` для безопасности.
