# UX_SPEC.md — Интерфейсная спецификация мастера смены пароля (TASK-07)

## 1. Состояния карточки «Управление паролем»

### Шаг 1: Начальное состояние (`#sec-step-init`)
- Заголовок: **«Управление паролем»**.
- Бейдж: `PBKDF2-HMAC-SHA256`.
- Описание: «Для защиты вашей учетной записи смена пароля выполняется с подтверждением через электронную почту **`user.email`**».
- Кнопка действия: **«🔐 Сменить пароль»** (`.btn-primary`).

### Шаг 2: Ввод кода подтверждения (`#sec-step-code`)
- Заголовок: **«Подтверждение по E-mail»**.
- Описание: «Мы отправили 6-значный проверочный код на адрес **`user.email`**. Введите его ниже:».
- Большое поле ввода кода: `.form-input-code` с моноширинным шрифтом и центрированием текста.
- Кнопки:
  - Кнопка **«Подтвердить код»** (`.btn-primary`).
  - Кнопка **«Отправить код повторно»** (с таймером обратного отсчета `Отправить повторно через 59 сек`).
  - Кнопка **«Отмена»** (`.btn-modal-cancel`) — возвращает на Шаг 1.

### Шаг 3: Установка нового пароля (`#sec-step-new-password`)
- Заголовок: **«Установка нового пароля»**.
- Поле «Новый пароль» с иконкой показать/скрыть (👁 / 🙈) и шкалой надежности.
- Поле «Подтверждение нового пароля» с иконкой показать/скрыть (👁 / 🙈) и статусом совпадения.
- Кнопки:
  - Кнопка **«Сохранить новый пароль»** (`.btn-primary`).
  - Кнопка **«Отмена»** (`.btn-modal-cancel`).
