# UX Specification: TASK-01 — Интерфейс авторизации и регистрации личного кабинета

## 1. Пользовательский сценарий и навигация (User Journey)
- Пользователь открывает модальное окно или страницу авторизации.
- По умолчанию активна вкладка **«Вход»**.
- Вверху расположен логотип платформы смарт-контрактов и понятный подзаголовок: *«Единая точка входа в экосистему смарт-контрактов»*.
- Быстрое переключение табов: `[ Войти ]` | `[ Зарегистрироваться ]`.
- Ссылка `Забыли пароль?` под полем ввода пароля плавно переключает карточку в режим сброса пароля с кнопкой `Вернуться ко входу`.

## 3. Матрица состояний интерфейса (UI States)
- **Default State**: чистые поля ввода с понятными плейсхолдерами (`ivanov@corp.ru`, `7707083893`).
- **Focus State**: подсветка границы активного поля фирменным акцентным цветом (#3B82F6 / #6366F1), вывод подсказки по формату.
- **Loading / Submitting State**: кнопка блокируется, текст заменяется на анимированный спиннер, поля ввода переходят в `disabled`.
- **Field Error State**: красная рамка у проблемного поля, под полем выводится конкретная подсказка (например: *«Пароль должен содержать минимум 8 символов и цифру»*).
- **Global Error State**: всплывающий алерт вверху формы с иконкой ошибки (например: *«Неверный логин или пароль»*).
- **Success State**: анимация галочки, сообщение об успешной отправке ссылки/подтверждения и автоматический редирект.

## 4. Логика валидации полей «на лету»
- **Email**: проверка регулярным выражением RFC 5322 при потере фокуса (`onBlur`).
- **Пароль**: моментальный расчет сложности при вводе (`onChange`):
  - *Слабый (Красный)*: < 8 символов.
  - *Средний (Желтый)*: >= 8 символов + цифры.
  - *Надежный (Зеленый)*: >= 8 символов + заглавные + спецсимволы (`!@#$%^&*`).
- **ИНН**: валидация длины (10 или 12 цифр) и только числового ввода.
- **Чекбокс согласия**: кнопка регистрации заблокирована, пока чекбокс не активен.

## 5. Доступность (a11y) и отзывчивость
- Корректные `aria-describedby` для сообщений об ошибках.
- Навигация клавишей `Tab`, отправка по `Enter`, закрытие модалки по `Esc`.
- Кнопка переключения видимости пароля (глаз) имеет понятный `aria-label="Показать пароль"`.
- Адаптивность: на экранах мобильных телефонов (< 640px) модальное окно разворачивается во весь экран для удобства набора на экранной клавиатуре.
