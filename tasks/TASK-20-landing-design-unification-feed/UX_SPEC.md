# UX_SPEC.md — Интерфейсная спецификация (TASK-20)

## 1. Компоненты UI
1. **Шапка**: Единый логотип, иконка ленты, кнопка «Выйти» с зеленой точкой.
2. **Hero-блок**: Парящий канвас частиц, заголовок с градиентами (`белый` $\rightarrow$ `электрик` $\rightarrow$ `изумруд`), полоса метрик с лазерными неоновыми разделителями.
3. **Панель создания**: Иконки действий в векторном формате в рамках `.creator-action-btn`.
4. **Карточки контента**:
   - Аватары с градиентным свечением.
   - Бейджи форматов и статусов (RFC, Архитектура, Кейс, Оракулы) с границами и полупрозрачным фоном.
   - SVG иконки для кармы (▲ / ▼), комментариев, просмотров, реакций, закладок и шеринга.
5. **Сайдбар и Футер**: Полная интеграция стиля главной страницы.
