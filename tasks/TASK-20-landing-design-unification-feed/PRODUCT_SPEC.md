# PRODUCT_SPEC.md — Продуктовая спецификация унификации дизайна Ленты (TASK-20)

## 1. Цель
Обеспечить 100% визуальную и стилистическую гармонию между Главной страницей и страницей «Лента»:
- Идентичные шрифты (Manrope для акцентных заголовков, Inter для интерфейса, JetBrains Mono для смарт-контрактов).
- Единый набор четких векторных SVG-иконок в неоновых градиентных рамках.
- Фоновый анимированный канвас с эффектом криптографических частиц/созвездия.
- Единые карточки с эффектом стекла и градиентными неоновыми бордерами.
- Единый футер с плашкой Umbrella Trust Protocol.

## 2. Критерии приемки
- **AC-01**: Стилистика, иконки, сетка и компоненты страницы «Лента» полностью соответствуют визуальному языку главной страницы.
- **AC-02**: Все интерактивные функции (голосование, комментарии, создание, фильтры) сохраняют работоспособность.
- **AC-03**: 30 из 30 тестов проходят успешно.
