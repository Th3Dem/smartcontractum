## 1. Цель
Сделать индикацию авторизации в шапке интуитивной и точной:
- Авторизован: горит зеленая точка `#10b981` на аватаре кнопки «Выйти».
- Не авторизован: точки нет вообще.

- **AC-02**: При наличии авторизации `#headerUserDot` отображается зеленым цветом `#10b981`.
