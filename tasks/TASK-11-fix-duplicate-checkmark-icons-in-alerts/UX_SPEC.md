# UX_SPEC.md — Интерфейсная спецификация уведомлений (TASK-11)

## 1. Типографика и оформление алертов
- **Левая иконка**: `✅` (для успешных операций) или `⚠️` (для предупреждений и ошибок).
- **Текстовая часть**: Чистый текст сообщения без лишних спецсимволов.
- **Примеры**:
  - `✅` `Пароль успешно обновлен!`
  - `✅` `Параметр успешно обновлен!`
  - `✅` `Код подтвержден! Теперь введите новый пароль.`
  - `✅` `Успешная авторизация! Перенаправление в личный кабинет...`
