# UX_SPEC.md — Интерфейсная спецификация индикатора сложности пароля (TASK-08)

## 1. Визуальный дизайн и состояния
1. **Состояние покоя / Пустой ввод**:
   - Полоска `.strength-bar-track` видна как тонкая нейтральная подложка 4px с закругленными краями (`border-radius: 99px`).
   - Заполняющая часть `.strength-bar-fill` имеет `width: 0%`.
   - Текст слева: `Сложность: —` (`#new-pwd-strength-label`).
   - Текст справа: `Мин. 8 знаков, заглавная буква, цифра`.
2. **Слабый пароль (1 критерий)**:
   - `width: 25%`, `backgroundColor: #EF4444` (Красный), `Сложность: Слабый`.
3. **Средний пароль (2 критерия)**:
   - `width: 50%`, `backgroundColor: #F59E0B` (Оранжевый / янтарный), `Сложность: Средний`.
4. **Хороший пароль (3 критерия)**:
   - `width: 75%`, `backgroundColor: #3B82F6` (Синий), `Сложность: Хороший`.
5. **Надежный пароль (4 критерия)**:
   - `width: 100%`, `backgroundColor: #10B981` (Зеленый), `Сложность: Надежный`.

## 2. Анимация
- Плавный переход ширины и цвета: `transition: width 0.3s ease, background-color 0.3s ease;`.
