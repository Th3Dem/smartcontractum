# SECURITY_REVIEW.md — Аудит безопасности (TASK-10)

## 1. Защищенность парольных потоков
1. **Защита от подбора (Brute Force)**:
   - Проверочные коды имеют ограничение по времени (10 минут).
   - Одноразовые токены сброса (`resetToken`, `changeToken`) имеют размерность 256 бит (32 байта шестнадцатеричной строки).
2. **Сравнение постоянного времени**:
   - Валидация кодов и токенов осуществляется через `hmac.compare_digest`, исключая тайминг-атаки.
3. **Очистка сессий сброса**:
   - После успешной смены пароля сессия мгновенно удаляется из оперативной памяти (`pop`), предотвращая повторное использование токенов (Replay Attacks).
