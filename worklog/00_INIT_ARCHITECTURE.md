## 1. Бизнес-контекст и миссия проекта

**SmartContractum** создается с нуля как независимый технологический и регуляторный шлюз (Umbrella-интегратор) к **Платформе Конструктор Смарт-Контрактов (ПКСК) Банка России**.

### Ключевые архитектурные вызовы:
1. **Регуляторная изоляция:** Независимые разработчики (физлица и ИП) не имеют прямого доступа к сертифицированному контуру ПКСК. SmartContractum берет на себя роль аккредитованного шлюза.
2. **UX «Вход от задачи пользователя»:** Пользователи не должны писать сложный программный код. Платформа визуализирует логику сделок в виде интерактивных **«деревьев решений»**.
3. **Отказоустойчивость уровня Enterprise:** Внешние LLM API могут давать сбои (429/503). Архитектура обязана поддерживать паттерн **Circuit Breaker** с мгновенным локальным детерминированным fallback-процессингом.

## 3. Детализация технологического стека (Enterprise Stack)

| Компонент | Выбранная технология | Обоснование выбора |
| :--- | :--- | :--- |
| **Backend Runtime** | Python 3.12 (Asyncio) | Нативная поддержка async/await, современный синтаксис generic-типизации, производительность. |
| **Веб-фреймворк** | FastAPI 0.115+ / Starlette | Асинхронная обработка высокой нагрузки, автогенерация OpenAPI схем, высокая скорость. |
| **База данных** | PostgreSQL 16 (`asyncpg` + SQLAlchemy 2.0) | Полная транзакционность (ACID), надежность при фиксации смарт-контрактов, аудит операций. |
| **Кэш и Очереди** | Redis 7+ | Хранение сессионных состояний, кэш LLM-ответов, очереди фоновых задач SAQ. |
| **ИИ-интеграция** | Google Gemini REST API v1beta | Structured JSON mode, Circuit Breaker (`pybreaker`), мгновенный локальный Fallback. |
| **Frontend Сборка** | Vite + Tailwind CSS v3 | Мгновенный HMR при разработке, нулевой оверхед в рантайме, обсидиановая тема Helias. |
| **Автотесты** | Pytest + Playwright + k6 | Полный пирамидальный охват: Unit, API, E2E браузерные тесты и нагрузочные стресс-тесты. |
| **Безопасность** | Bandit, Trivy, CSP, WAF | Подготовка к пред-аудиту Standoff 365 / BI.ZONE и соответствию стандартам ЦБ РФ. |

## 4. Релизный протокол (Staging Gate Protocol)

```
[feature/*] ──► [dev] ──► [staging (Авто-тесты Pytest+Playwright+k6)] ──► [main (Production)]
```
- **Запрет:** Прямой коммит или авто-мердж в `main` заблокирован.
- **Критерий допуска (Gatekeeper Approval):** 100% зеленый отчет тестов + 0 уязвимостей High/Critical.
