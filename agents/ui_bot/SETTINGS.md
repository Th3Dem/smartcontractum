## 1. Регламент верстки и интерфейсной оптимизации

1. **Производительность графики (Zero Cost Canvas & 3D):**
   - Запрещено использовать ресурсоемкие свойства `ctx.shadowBlur` и динамические `backdrop-filter: blur()` внутри 3D-анимируемых элементов (вызывают постоянную растеризацию на каждом кадре).
   - Все 3D-элементы обязаны иметь аппаратный промоушн:
     ```css
     will-change: transform;
     transform: translateZ(0);
     backface-visibility: hidden;
     ```
   - Циклы `requestAnimationFrame` обязаны вставать на паузу при уходе элемента из зоны видимости (`IntersectionObserver`) или скрытии вкладки (`visibilitychange`).

2. **Типографика и балансировка строк:**
   - Для предотвращения висячих строк в подзаголовках использовать свойство `text-wrap: balance;`.
   - Ключевые регуляторные названия и сущности оформлять с неразрывным пробелом:
     ```html
     <span class="text-nowrap">Банка&nbsp;России.</span>
     ```

3. **Сетка и структура первого экрана (Hero Fold):**
   - Первый экран занимает изолированную высоту: `min-height: calc(100vh - 72px)`.
   - Нижние блоки (селектор задач, лента) отделяются комфортными отступами и открываются только при намеренном скролле.

## 2. Организация файлов интерфейса

```
frontend/
├── static/
│   ├── css/
│   │   ├── base.css       # Глобальные переменные, сброс, навигация, футер
│   │   ├── hero.css       # Стили первого экрана, 3D-куб, орбиты, сетка 6 карточек
│   │   ├── builder.css    # Стили Конструктора решений и деревьев
│   │   └── passport.css   # Стили мастера Паспортов
│   └── js/
│       ├── base.js        # Общие UI-хелперы, уведомления, темы
│       └── hero.js        # Движок 3D-физики, реактивный Canvas созвездий, модальные окна
└── templates/             # Jinja2 шаблоны страниц
```

## 3. Регламент логирования в WORKLOG.md

В каждой записи `WORKLOG.md` раздел `ui_bot` обязан содержать:
* Измененные шаблоны `frontend/templates/...` и файлы стилей/скриптов.
* Реализованные визуальные эффекты, физические модели или селекторные улучшения.
* Подтверждение адаптивности и высокой производительности (60 FPS).
