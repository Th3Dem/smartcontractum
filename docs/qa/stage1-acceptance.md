# Критерии приемки и регламент тестирования (Этап 1)

**Проект**: SmartContractum  
**Автор**: `qa_bot` / `pm_bot`

---

## 1. Главный пользовательский критерий первого этапа (5-Second Test)
Пользователь при переходе в Сообщество за 5–10 секунд должен однозначно понять:
1. Это профессиональное сообщество и база знаний рынка коммерческих смарт-контрактов.
2. Здесь можно быстро задать вопрос экспертам или найти готовое решение.
3. Здесь можно опубликовать статью, кейс или пост.
4. Здесь можно участвовать в профессиональных обсуждениях стандартов (RFC).
5. Здесь можно формировать подтвержденную репутацию и демонстрировать компетенции.
6. Здесь нет впечатления государственного портала Банка России или крипто-казино.

---

## 2. Чек-лист функциональной верификации
- [x] **Навигация**: Переход между «Главная», «Сообщество», «База знаний», личным кабинетом.
- [x] **Быстрое создание**: Кнопка `+ Создать` открывает модалку с типами (Вопрос, Статья, Обсуждение, Кейс, Пост).
- [x] **Живая фильтрация**: Работа фильтров «Для вас», «Подписки», «Вопросы», «Статьи», «Обсуждения», «Кейсы».
- [x] **Живой поиск**: Поиск по заголовкам, авторам, организациям и тегам с очисткой по кнопке ✕.
- [x] **Социальные действия**: Оценка «Полезно», разворачивание веток ответов/комментариев, добавление в закладки.
- [x] **Темы оформления**: 100% корректность и контрастность темной и светлой тем (WCAG AA).
- [x] **Регрессия**: 30 / 30 unit/integration тестов проходят со статусом `OK`.
