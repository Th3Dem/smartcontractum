# Аудит текущего состояния localhost-прототипа SmartContractum (Этап 1)

**Дата аудита**: 2026-09-01  
**Версия системы**: `v2.20.0`  
**Роль аудитора**: `pm_bot`

---

## 1. Технологический стек и архитектура
- **Runtime**: Python 3.14 (HTTP-сервер `ThreadingHTTPServer` с многопоточной обработкой).
- **Frontend**: Чистый HTML5 / CSS3 / Vanilla ES6+ JavaScript (без тяжелых SPA-фреймворков), модульная структура стилей:
  - `landing_main.css` — стили посадочной страницы;
  - `hero_constellation.css` — 3D-анимация и холст интерактивных связей;
  - `forum_social.css` / `forum_editor.css` — стили ленты публикаций, виджетов, модальных окон, темная и светлая темы;
  - `dashboard.css` — стили личного кабинета.
- **Backend & API**: Сервер `server.py` реализует REST API endpoints:
  - `/api/auth/register-send-email`, `/api/auth/verify-email` — регистрация с отправкой 6-значного кода через SMTP;
  - `/api/auth/login`, `/api/auth/logout`, `/api/auth/me` — аутентификация по токенам сессий (Bearer Token);
  - `/api/auth/forgot-password`, `/api/auth/forgot-verify-code`, `/api/auth/forgot-reset-password` — сброс пароля;
  - `/api/security/request-password-change`, `/api/security/verify-password-code`, `/api/security/change-password-verified` — смена пароля в кабинете;
  - `/api/user/update-profile`, `/api/user/change-password` — редактирование профиля;
  - `/api/contracts` — реестр смарт-контрактов пользователя;
  - `/api/v1/system/stats` — системная статистика экосистемы;
  - `/api/egrul` — двухэтапный прокси-запрос к API ФНС России (`egrul.nalog.ru`) с парсингом ИНН/ОГРН/ФИО.
- **База данных**: SQLite (`data/smartcontractum.db`) с криптографической защитой паролей PBKDF2-HMAC-SHA256 (100 000 итераций) и поддержкой 152-ФЗ.

## 2. Карта существующих экранов и маршрутов
1. `/` (`public/index.html`) — Главная посадочная страница экосистемы с 3D-созвездием связей, описанием фазы НИР, калькулятором и интерактивным деревом решений.
2. `/auth`, `/login`, `/register` (`public/auth.html`) — Унифицированный экран входа и пошаговой регистрации (Физлица, ИП, Организации) с интеграцией ФНС ЕГРЮЛ.
3. `/dashboard` (`public/dashboard.html`) — Личный кабинет участника: профиль, инлайн-редактирование параметров, безопасность, реестр контрактов.
4. `/feed`, `/forum` (`public/feed.html`) — Лента сообщества и база знаний (Хабр 2.0).
5. `/editor` (`public/editor.html`) — Редактор статей с панелью форматирования и превью.

## 3. Анализ текущей реализации Ленты (`public/feed.html`, `public/forum_social.js`)
### Что работает реально:
- **Переключение тем (Dark / Light)**: Кнопка в шапке с хранением в `localStorage.getItem('sc_theme')` и анти-флеш скриптом в `<head>`.
- **Живая фильтрация карточек**: По типам публикаций (`data-hero-tab`), категориям (`data-cat`) и поисковому запросу (`feedHeroSearchInput`).
- **Интерактивные опросы**: Голосование в RFC-карточке с пересчетом процентов, анимацией прогресс-бара и toast-уведомлением.
- **Интерактивные комментарии**: Разворачивание ветки комментариев (`.btn-thread-toggle`), добавление нового комментария через поле ввода с отображением текущего пользователя.
- **Социальные действия**: Оценка полезности/карма (`.karma-lever`), реакции смайликами (`🔥`, `🚀`, `💡`, `👏`), добавление в закладки (`.btn-bookmark-post`), копирование ссылки (`.btn-share-post`), копирование кода Solidity (`.btn-copy-code-snippet`).
- **Модальное окно создания**: Кнопка «Написать» открывает модалку с вкладками (Пост, Вопрос, Опрос, Кейс), добавлением вариантов ответов и публикацией новой карточки в поток.
- **Холст частиц**: Canvas-анимация созвездия в шапке ленты с адаптацией цвета под светлую/темную тему.

### Что является mock / demo:
- Серверное сохранение (persistence) новых постов и комментариев ленты (сейчас добавляются в DOM на клиенте).
- Персонализированная лента подписок (пока клиентский fallback).
- Статистика просмотров карточек (статичные демонстрационные бейджи).
- Подписки на авторов в лидерборде (кнопка `+` меняет состояние в памяти интерфейса).

## 4. Выявленный технический долг и продуктовые ограничения
1. **Навигация**: В главном меню ленты закреплены ссылки «Главная», «Лента», «Редактор». По целевой концепции верхний уровень должен быть «Главная / Сообщество / База знаний», а создание контента вызываться через понятный CTA «+ Создать».
2. **Типы фильтров**: В текущей строке фильтров смешаны типы контента («Статьи», «Посты», «Новости») и типы сущностей («Авторы», «Компании»). По целевой модели «Авторы» и «Компании» должны искаться через глобальный поиск и каталог участников, а фильтры ленты должны быть: «Для вас», «Подписки», «Вопросы», «Статьи», «Обсуждения», «Кейсы».
3. **Q&A как самостоятельное ядро**: Вопросы должны иметь статус решения, четкую привязку «Принятый ответ», отображение компетенции автора и вознаграждения (баунти/репутация).
4. **Сайдбар ленты**: Статичный блок этапов экосистемы занимает ценное место. Его необходимо эволюционно трансформировать в динамические модули: «Сейчас обсуждают», «Ждут ответа», «Эксперты сообщества».
5. **Риск ложной официальности**: Демо-карточки не должны создавать ложного впечатления официальных аккредитаций или заявлений Банка России (необходимо использовать маркировку DEMO / Общественные консультации / Демо-профиль).
