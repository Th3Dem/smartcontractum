# Спецификация типов контента экосистемы SmartContractum (Этап 1)

**Проект**: SmartContractum  
**Автор**: `pm_bot`

---

## 1. Спецификация типов публикаций

### 1. QUESTION (Вопрос)
- **Назначение**: Постановка инженерной, юридической или архитектурной задачи.
- **Обязательные поля**:
  - Заголовок (четкая формулировка вопроса);
  - Описание проблемы / контекст / сниппет кода;
  - Тематическая категория (`cat`) и теги (`tags`);
  - Статус решения (`open`, `solved`);
  - Награда / Баунти (опционально);
  - Список ответов (`answers`);
  - Идентификатор принятого ответа (`accepted_answer_id`).
- **Специфика UI**: Выделенный блок принятого ответа зеленого цвета, счетчик ответов, кнопка «Ответить».

### 2. ARTICLE (Статья)
- **Назначение**: Глубокий экспертный лонгрид, архитектурный гайд, анализ стандарта.
- **Обязательные поля**:
  - Заголовок и лид (краткое резюме);
  - Основной текст (поддержка Markdown, заголовки H2/H3, списки, цитаты, блоки кода с подсветкой синтаксиса и оценкой газа);
  - Сложность материала (`Базовый`, `Средний`, `Сложный`);
  - Расчетное время чтения (`⏱️ N мин`);
  - Источники и нормативные ссылки.

### 3. DISCUSSION / RFC (Обсуждение и открытые консультации)
- **Назначение**: Обсуждение стандартов разработки и регулирования, сбор предложений рынка.
- **Обязательные поля**:
  - Заголовок RFC (например: `RFC-04: Модель интеграции доверенных оракулов`);
  - Контекст консультаций;
  - Интерактивное голосование (варианты ответов, прогресс в %, общее количество голосов, срок завершения);
  - Ветка экспертных аргументов и комментариев.

### 4. CASE (Паспорт сценария / Кейс внедрения)
- **Назначение**: Демонстрация отраслевого внедрения смарт-контракта (B2B расчеты, логистика, факторинг).
- **Обязательные поля**:
  - Бизнес-задача;
  - Требуемые внешние данные и интеграции (1С, Диадок, ЕИС Закупки);
  - Достигнутый бизнес-эффект (например, «С 14 дней до 30 секунд»);
  - Схема логики («Дерево решений» / IF-THEN).

### 5. POST (Инсайт / Короткая публикация)
- **Назначение**: Оперативный обмен мыслями, анонс, технический инсайт.
- **Обязательные поля**: Текст до 1500 символов, теги, вложения/ссылки.
